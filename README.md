# Home Credit Default Risk (GCI): credit-default prediction

Final submission for the GCI competition (dataset `kiethe/homecredit-gci`). Task: predict the probability that a loan applicant defaults (`target`, default rate 8.07%). Metric: ROC AUC. The submission file contains probabilities.

## Contents

| File | Purpose |
|---|---|
| `gci-model-final-en.ipynb` | Full pipeline: data cleaning, feature engineering, cross-validation, LightGBM, CatBoost, blend, refit on 100% of the data, `submission.csv` |
| `gci-eda-en.ipynb` | Exploratory data analysis (companion notebook; produces no model output) |
| `README.md` | This file |

## Approach in brief

1. **Cleaning.** Lower-cased columns; `days_employed == 365243` (the "no employment record" code) becomes missing; all divisions are safe (zero denominator gives NaN).
2. **Features (all label-free).**
   - 70 base features: raw numerics, times in years, label-coded categoricals, affordability ratios, `ext_source_1/2/3` aggregates and interactions.
   - ML imputation of the three `ext_source` scores (LightGBM regressors, observed values never changed).
   - Loan-term block (nominal term, interest estimate) and a **pricing block**: implied annual interest rate solved from credit and annuity on a standard term grid, plus credit-over-goods fee features.
   - **Term-context features**: z-score and percentile of `ext_source` inside peer groups of loans with similar term and size.
3. **Target encoding** (the only place the label is used): smoothed and residual encodings, rebuilt inside every fold with an inner out-of-fold scheme to avoid leakage.
4. **Models.** LightGBM (108 inputs, 5 seeds) and CatBoost (94 inputs with native categoricals, 5 seeds), 5-fold stratified CV (seed 42).
5. **Blend.** `sigmoid(0.6 * logit(LightGBM) + 0.4 * logit(CatBoost))`.
6. **Final training.** Both models refit on 100% of the training rows with trees = mean CV best iteration x 1.1; a safety check (logit correlation >= 0.98 with the CV-average predictions, mean ratio within 10%) falls back to the CV average if it fails.

Expected cross-validated AUC of the blend: about 0.767 to 0.768. An earlier version without the pricing block scored 0.77 on the public leaderboard.

## How to run

1. Put `train.csv`, `test.csv` (and optionally `sample_submission.csv`) in the Kaggle dataset path `/kaggle/input/datasets/kiethe/homecredit-gci`, or in the notebook's working directory.
2. Requirements: Python 3, `numpy`, `pandas`, `scikit-learn`, `scipy`, `lightgbm`, `catboost`, `matplotlib`, `jupyter`. Versions are printed in section 1 of the notebook.
3. Run all cells of `gci-model-final-en.ipynb`.
   - Full run on a Kaggle CPU session: about 3 to 4 hours (LightGBM ~15 min, CatBoost ~2 h, refit 15 to 25 min).
   - Smoke test: set `DEBUG_FAST = True` in the setup cell (20k rows, few trees, a few minutes). Keep it `False` for the real run.
4. Outputs (written to `/kaggle/working` on Kaggle, otherwise the current folder):
   - `submission.csv`: the file to submit (refit predictions, or the CV average if the safety check fails)
   - `submission_cv_average.csv`: CV-average alternative
   - `tutorial.zip`: the notebook compressed (section 12, required for Honors/Outstanding). If the notebook file is not detected, set `NOTEBOOK_FILE` in the last cell.

## Rules compliance

- **No external data.** Only `train.csv`, `test.csv` and, for the column format only, `sample_submission.csv`.
- **No hand-labeling.** All predictions are generated by the models; no manual decisions on individual rows or rules derived from EDA are applied to predictions.
- **Reproducibility.** `PYTHONHASHSEED`, Python/NumPy seeds, CV splitter, inner target-encoding splitters and imputers use seed 42; LightGBM seeds (42, 7, 2024, 11, 99); CatBoost seeds (42 to 46); LightGBM runs with `deterministic=True`, `force_row_wise=True`. Small numerical differences are possible across library versions or machines.
- **Label-free transductive statistics.** The `ext_source` imputers, the peer-group z-scores/percentiles and the category codes are computed on train and test features together. No label is used. This is disclosed in section 10 of the notebook.
- **Sources.** Cited in section 11 (LightGBM, CatBoost, target encoding, scikit-learn, Home Credit column documentation). Edit the "reference code" and "AI assistance" lines there to match your situation.

## Limitations

- The CV score is measured on 80% models; the submitted refit models cannot be scored directly.
- Early stopping uses the validation fold, so CV is slightly optimistic.
- The pricing block assumes a standard term grid; it is a feature, not a certified interest rate.
- The last additions (pricing, term-context) give small gains compared with the fold-to-fold standard deviation (about 0.003); they were accepted only after a paired per-fold test confirmed on a different fold split.
